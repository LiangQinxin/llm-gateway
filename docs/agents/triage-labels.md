# Triage 标签

这些技能使用五个标准 triage 角色。本文件将这些角色映射为本仓库问题跟踪器中实际使用的标签字符串。

| 标准角色            | 本跟踪器中的标签   | 含义                                      |
| ------------------- | ------------------ | ----------------------------------------- |
| `needs-triage`      | `needs-triage`     | 维护者需要评估该问题                      |
| `needs-info`        | `needs-info`       | 等待报告人补充更多信息                    |
| `ready-for-agent`   | `ready-for-agent`  | 规格完整，可供 AFK Agent 直接实现         |
| `ready-for-human`   | `ready-for-human`  | 需要人工实现                              |
| `wontfix`           | `wontfix`          | 不会处理                                  |

当技能提到某个角色（例如"应用 AFK-ready triage 标签"）时，使用上表中对应的标签字符串。

如需改用其他命名，直接编辑右列即可。
